## 🚀 About the Project

This repository houses the front-end assets, interactive scripts, SEO optimization files, and Nginx web server configurations powering the Web Technics Services platform.

### Built With
* **JavaScript (ES6+)** - Dynamic site features and analytics integration
* **HTML5 / CSS3** - Responsive design and modern layout
* **Nginx** - Web server routing, performance caching, and SSL configuration
