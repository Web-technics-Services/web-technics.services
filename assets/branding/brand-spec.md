# Web Technics Logo Spec

## Core Palette
- Background: #061217
- Surface: #0B1F27
- Primary brand: #3ED1BD
- Secondary highlight: #FFB55A
- Supporting blue: #53A8FF
- Text on dark: #E9F4F5
- Muted text: #A9C2C7

## Delivered Variants
- Horizontal primary: web-technics-logo-horizontal.svg
- Horizontal on light background: web-technics-logo-horizontal-light.svg
- Square icon: web-technics-icon-square.svg
- Monochrome: web-technics-logo-monochrome.svg
- Favicon icon: web-technics-icon-favicon.svg

## Usage Guidance
- Use horizontal primary for website headers and presentations.
- Use square icon for social profile images and app icons.
- Use favicon icon for browser tab/favicon workflows.
- Use monochrome for emboss, print, or limited-color contexts.
